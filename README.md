# 🛸 Rick and Morty — Personagens

Aplicação front-end que consome a [Rick and Morty API](https://rickandmortyapi.com/) para exibir, buscar e navegar entre os personagens do desenho. Projeto acadêmico de **Web Programming Front-End** **UniFECAF**.

---

## 🔗 Links

- **Projeto publicado:** https://wellingtondsilva.github.io/trabalho-uniFecaf-WEB-PROGRAMMING-FRONT-END/
- **Vídeo pitch:** https://youtu.be/TpXS5HiTJeM
- **Documentação da API:** https://rickandmortyapi.com/documentation

---

## ✨ Funcionalidades

- 🔍 Busca por nome
- 📄 Paginação entre todas as páginas da API
- 🔄 Botão para limpar filtro
- 📱 Layout responsivo
- ⚠️ Tratamento de erros e estado de carregamento

---

## 🛠 Tecnologias

**HTML5 · CSS3 · JavaScript · Fetch API**

> Sem frameworks — apenas HTML, CSS e JavaScript puros.
